# 0.6.3 发布报告

日期：2026-10-12。基于0.6.2，整理0.6.2打包后的未发布改动并为上传 GitHub 做准备。不增加产品功能。

## 改动

1. **宿主身份缓存**（`desktop/host.cjs`）：按 Antigravity.exe 与 app.asar 的路径、修改时间和大小缓存版本与 SHA-256，未变化时不再每次重新读取整个 app.asar。读取失败不缓存，下次重试；宿主更新（文件变化）后重新哈希。返回副本，调用方不能改写缓存。
2. **调试端口缓存**（`desktop/theme-service.cjs`）：端口归属缓存由 5 秒延长到 30 秒；CDP 请求失败或断开时立即清除，到期重新验证归属。
3. **遗留调试端口文件**（`desktop/host.cjs`）：Antigravity 已关闭或崩溃后 `DevToolsActivePort` 仍在时，原先把原始 PowerShell 错误（乱码）抛给界面。现在无监听时提示“请先启动 Antigravity Desktop，再点击重新检测”，查询失败（含非本机回环监听）提示“无法确认 Antigravity 调试端口归属，请重新检测”。安全判断不变。
4. **精选壁纸**：`scripts/catalog-art.cjs`、`scripts/build-round5-catalog.cjs` 更新，重新生成 20 套壁纸与预览（`assets/catalog/`）。包校验确认 20 项精选完整。
5. **仓库整理**：`.gitignore` 增加 `.backups/`、`*.tmp`；CI 改为 `windows-latest` 并安装 Playwright Chromium（原 ubuntu 配置缺浏览器，渲染测试必然失败）；两份文档中的本机用户目录改为 `%LOCALAPPDATA%`；README 去掉指向未入库 `release/` 的过期说明。
6. 两个 Electron 冒烟脚本把“请先启动 Antigravity”识别为合法的无宿主结果。
