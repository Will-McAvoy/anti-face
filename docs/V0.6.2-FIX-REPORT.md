# 0.6.2 扫描、直接修复与验收

日期：2026-10-12。用户授权扫描后直接修复，仅处理影响使用的问题。

## 执行进度与修复

开工源码0.6.1，安装包已存在，初始全量260项通过。上一轮摘要接口、轮换上下文已接通。但扫描确认仍有备份校验/归属、轮换取消/资源及摘要过期确认遗漏；已直接修成0.6.2。

1. **自动备份校验失败不再吞掉**：inspectBackup抛错或返回无效时，删除本次不合格文件，返回BACKUP_CORRUPT，不更新成功时间、指纹或托管索引，不清理旧备份。检查会话用真实cancelInspection释放。
2. **不凭文件名认领用户文件**：删除空索引时扫描认领的逻辑，仅清理现有托管记录；保留其他目录记录，校验当前文件为授权目录内普通文件，跳过symlink和不可验证文件。失败不借保留清理删用户文件。
3. **轮换停止/新操作失效**：增加运行操作epoch，并检查目标实例、operationGeneration及当前文档。暂停、改配置、stop或drop使旧任务失效，原生无主题窗口不回退全局草稿。
4. **异常不泄漏临时资产租约**：decorate/apply抛错时释放本次引用，已确认旧图保持。正常失败和stale路径同样不提交新图。
5. **摘要确认绑定当前草稿和目标状态**：preview保存目标操作代次，确认检查目标、断开、代次和前端当前文档；App提交currentDocument和selectedTargetId。发生变化拒绝旧确认并消费失效会话。
6. **版本/锁文件同步**：0.6.1时锁文件根仍为0.5.1。本轮package和lock根均为0.6.2，根依赖声明与package一致，没有主动升级依赖。

没有重新设计五项UI、增加新产品功能或处理无关格式问题。对两项旧测试调整的是夹具语义：托管文件要显式登记归属，轮换正例要具备目标已应用文档，未放宽成功断言。
