# Anti Face v0.6.0 版本发布说明 (Release Notes)

发布日期：2026-10-12
版本：v0.6.0
代号：Round 7 Comprehensive Delivery

Anti Face v0.6.0 是面向 Windows 桌面端 Antigravity 客户端的重磅功能版本。本版本在延续 v0.5.x 坚实安全基线与双向无损编辑能力的基础上，正式推出了用户期盼的五大核心能力：主题标签与多维分类、本地壁纸文件夹自动轮换、应用前变化摘要与诚实反馈、主题局部复制、以及具备保底安全策略的自动备份系统，同时彻底修复了性能自适应状态恢复的遗留缺陷。

---

## 🌟 新增功能与体验升级

### 1. 主题标签与多维分类 (F01)
- **主题卡片标签展示与编辑**：主题库中的每个主题支持添加、移除自定义标签（如“编程”、“沉浸”、“阅读”、“极简”等），支持中英文混合输入与逗号/空格分隔快捷键。
- **多维度高效筛选栏**：
  - **标签多选**：支持多标签组合筛选，提供 **全部满足 (AND)** 与 **任一满足 (OR)** 语义一键切换；
  - **色彩方案自动识别**：根据背景相对亮度精确分类深色与浅色主题；
  - **壁纸与收藏过滤**：支持“有壁纸 / 无壁纸”、“仅看收藏”、“无标签待整理”快速筛选。
- **持久化与包流通保障**：标签作为主题库元数据原子持久化，导入/导出主题包及完整系统备份包均完整保留标签数据。

### 2. 本地壁纸文件夹自动轮换 (F02)
- **安全高效的本地扫描**：选择本地任意壁纸文件夹即可启动自动轮换；内置严格的安全保护（深度不超过 3 层，上限 2000 张，魔数自动校验排除虚假损坏图片，严禁选入应用内部数据目录）。
- **Shuffle Bag 无重复乱序播放**：采用袋装无放回随机算法，新一轮重新装填时自动比较首尾，杜绝跨周期相邻连续出现同一张壁纸。
- **无损运行期覆盖**：壁纸轮换作为运行时有效外观覆盖生效，**绝不频繁覆写用户已保存的主题 JSON，不产生膨胀的无效版本历史**。
- **显式存入主题**：当遇到特别喜爱的壁纸时，可在控制面板一键点击“存入当前主题”，将其正式固化为持久化主题版本。
- **安全与专注保护**：在安全模式、主题试穿预览或手动恢复保护期间，壁纸轮换自动安全暂停。

### 3. 应用前变化摘要与诚实结果反馈 (F03)
- **知情换肤（Pre-apply Summary）**：在点击“应用”前，可随时点击“变更摘要”或通过确认弹窗查看本次操作的精确变更清单：
  - **原生基线透明**：首次对原生窗口换肤时，清晰标注基线为“原生默认”，诚实展示将要生效的请求值，拒绝伪造原生旧值；
  - **已换肤精确对比**：已换肤窗口基于上一次验证通过的基线对比，字段级呈现调色板、排版、壁纸与区域样式的修改前与修改后；
  - **运行期自动叠加层提示**：明确标注当前生效的省电模式模糊度削减、场景感知优化或壁纸轮换覆盖。
- **诚实结果反馈**：注入后若出现宿主重载或版本历史落盘受阻，界面直接显示具体状态码与重试入口，拒绝假报全成功。

### 4. 主题局部复制 (F04)
- **模块化搭积木混搭**：在外观编辑面板点击“从其他主题复制部件”，可从个人主题库中自由挑选源主题并组合导入指定部分：
  - 配色调色板 (`colors`)
  - 排版与正文字号 (`typography`)
  - 壁纸资产与构图参数 (`wallpaper`)
  - 侧边栏 / 聊天区 / 输入框 / 卡片等单个区域样式 (`regions.*`)
- **跨基底主题视觉穿透**：当源主题基于不同基底主题且调色板为空时，智能解析源主题在宿主呈现的真实视觉颜色并填充，防止颜色降级回退。
- **身份保护与单步撤销**：严禁覆盖当前主题的 ID 与名称；整批局部复制作为单步原子操作存入草稿撤销栈，点击一次“撤销”即可完全复原。

### 5. 自动备份与严格保留策略 (F05)
- **全自动后台守护**：支持在发生重大主题修改后自动防抖备份（120 秒防抖，最小间隔 5 分钟），或每日执行一次定时备份。
- **数据指纹去重**：备份前校验关键配置的 SHA-256 指纹，无改动时不产生重复备份文件。
- **保底安全与隔离保护**：
  - 自动备份生成的 `.antiface-backup` 遵循规范命名；
  - 保留策略清理时**仅识别自动备份文件**，绝不误删用户手动导出的 zip 归档或目录下的其他个人文件；
  - 无论设置保留多少天或多少份，**算法始终强制保底保留 1 份最新的有效自动备份**，杜绝意外清空。
- **安全启动协同**：安全模式与迁移恢复期间自动挂起备份，杜绝脏读。

### 6. P2 级性能自适应恢复修复 (Grok v0.5.2 Baseline Fix)
- 解耦期望档位 (`desiredTier`) 与宿主已确认生效档位 (`confirmedTier`)；
- 引入有限重试机制（最多 3 次），彻底解决了初次 apply 临时失败后不再重试、导致界面显示省电但客户端未降级模糊度的长效同步缺陷。

## 🔒 安全与隐私承诺

1. **零外部网络通信**：所有图片处理、标签检索、文本比对、备份解压缩均完全运行在本机主进程中，不向任何第三方服务器上传任何资产或个人数据。
2. **防递归打包与遍历隔离**：壁纸目录与自动备份目录均包含严格的沙箱与路径边界判定，拒绝一切将内部 `userData` 作为备份目标的请求。
3. **确定性与无损回退**：所有宿主注入遵循明确的意图代际屏障，一键恢复（Restore All）与安全模式（Safe Mode）拥有绝对最高优先级，确保随时一键秒级恢复官方原始纯净外观。

## 📦 安装与升级说明

- 本版本向前完全兼容 Schema 1 规范的主题文件与现有备份包。
- 升级方式：直接运行便携版 `release/Anti Face 0.6.0.exe` 或解压版 `release/win-unpacked/Anti Face.exe` 即可自动承接既有数据。
