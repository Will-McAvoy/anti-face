# Anti Face 0.4.0

这一版仍是 Windows 上的本地 Antigravity 主题工作室。没有账号，没有社区，也没有云端配色。

## 你可以做什么

打开「阅读与精选」。

1. 阅读保护：先看对比。自动保护只影响这一次效果。点“采用到主题”才写进主题。
2. 诊断：重新检查连接、场景和区域。导出不含聊天和完整项目路径。
3. 场景：可关闭、自动，或固定首页/聊天。自动识别不稳定时不会来回跳。
4. 构图：框出主体和文字留白。拖一次只记一次。
5. 真实对比：对已连接窗口拍之前和之后。画面只留在内存里，除非你导出。
6. 整套配色：用当前壁纸在本机生成三套颜色。取消或关掉面板不会留下上一张图的候选。
7. 项目外观：识别到稳定项目后可以绑定主题。只绑定当前窗口的话，下次打开不会恢复。
8. 版本：恢复先成为草稿，确认后才变成新的当前版本。
9. 精选：20 套主题离线可用。远程源未配置。加入个人库不会马上换肤。你改过的副本不会被悄悄覆盖。

## 迁移

旧主题打开后会补上阅读保护关闭、场景关闭和手动构图。原来的颜色、透明度和壁纸焦点不变。个人库和旧设置的文件版本没有一起加一。

如果某个配置文件比这个版本更新，程序会停止写入并留下原文件。

## 限制和恢复

- 对比度是估算，不是无障碍认证。
- 没有连上 Antigravity 时，诊断、场景自动切换和真实截图都不会假装成功。
- 像素不同不能证明主题失败或成功。以诊断和应用后的核对为准。
- 核对失败会尝试回到上一次确认生效的样式。如果恢复本身也没确认，界面会说明，不会报成已保存。
- 换肤仍只作用于已验证的本机 Antigravity。关闭 Anti Face 后，宿主里的临时样式会按原来的租约恢复。
