日期：2026-10-08（Asia/Taipei）。本报告取代 0.5.0 的“七项模块 smoke 即全部完成”结论。原复核、review-050 脚本、结果和历史 EXE 均保留。无 Git 元数据；修改前备份位于 `.backups/round6-fix-2026-10-08/`。

## 备份与迁移（R01、R02）

主进程对话框负责选文件；renderer 不再往返 Buffer 或源路径。inspect 返回 UUID 检查令牌、摘要和 manifest，preview/commit 只引用主进程检查会话。最多三个会话，五分钟过期，取消、成功和文件变化释放；包哈希和预览时目标库快照均在提交前核对。

导出在 Store 写队列协调期间读取一致快照，任何引用资产缺失即失败。包括主题壁纸、缩略图、当前外观，以及选择的偏好、绑定和递归历史记录；已删除历史不重新导出。导出包本身再次检查后才替换目标文件。

恢复在隔离目录用真实 AssetStore 的受控图片导入重建 assets/files、索引、MIME、尺寸、哈希和引用。资产按内容去重，主题冲突副本使用合法 UUID；同步重写外观、规则、绑定和历史引用，冲突历史使用独立 revision ID，重复导入不会重复历史或复活 retired 记录。

先检查版本、路径、实际解压输出上限、重复路径、文件哈希、图片尺寸与内容、文档和历史索引引用，随后准备完整新状态与旧快照。持久 `restore-operation.json` 日志落盘后才修改 live 数据。committed 标记前的进程中断恢复完整旧状态，标记后保留完整新状态。启动时在读取 Store 前恢复；发布新 Store 内存后才释放写队列。回滚失败冻结写入并保留日志和材料，报告 RECOVERY_NEEDED，绝不虚报已回滚。这是带恢复日志的事务，并非宣称多个文件 rename 天然整体原子。

恢复默认关闭导入的自动规则、快捷键和通知；绑定禁用并标记重新关联，真实运行服务同步内存并停止自动任务。恢复界面提供范围选择和取消按钮。

## 安全模式与快速切换（R03、R04）

安全模式同步失效操作代际、暂停试穿和自动任务、取消自动重连资格、清性能状态和快捷键。Studio、Round5 场景/意图，以及真正写 CSS 的 ThemeService 都检查屏障；明确恢复原貌仍可用。真实任务声音和桌面通知在发送层抑制。用户主动试听、测试通知作为显式测试动作允许。

首次不干净启动和损坏标记先进入屏障，主窗口展示“保持安全模式/正常继续”。连续异常仍记录失败计数。退出保留此前设置资格，不重放旧任务，原本关闭的功能继续关闭。

切换器不再吞保存/取消异常；返回真实失败、未结束和部分历史失败，保留冲突面板。部分历史失败使用现有 operationId 重试。冲突绑定目标实例和所选主题，目标变化使原请求失效。普通编辑草稿通过编辑会话同步并参与冲突检查。新增 quickSwitcher 默认空绑定、默认不注册；校验、迁移、UI、注册和分发均接通，输入完成后提交，注册冲突保留旧有效配置。

## 性能、显示与撤销资产（R05、R06）

main 注入真实 Electron powerMonitor；不支持时返回 unknown。性能偏好保存到 PreferencesStore。电源事件及有界周期观测调用真实策略，发生变化后通过目标意图、effective resolver 和验证应用运行时覆盖。电池省电档模糊上限 8px；市电经过冷却恢复用户效果，关闭策略也恢复效果，不改保存的主题或添加撤销/历史。advisory 不自动应用。当前没有可靠 FPS 采样，界面和验收明确注明，仅交付可靠电源驱动的自动策略。

screen 变化有实际 Controller 处理者，主窗、迷你窗和切换器按真实 workArea 重新夹持；保留负坐标。DisplayService start 幂等，stop 移除监听。宿主 CDP 只观测宽高、DPR、可见性和聚焦，不读取聊天内容；实例/视口变化使旧意图、建议、截图和性能状态失效。截图使用宿主坐标，过期结果不能组成对比。
