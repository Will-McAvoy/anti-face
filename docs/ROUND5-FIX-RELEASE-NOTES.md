## 1. 版本概述

Anti Face v0.4.1 是基于第五轮深度审阅与全链路贯通后推出的高可靠性维护版本。本版本重点解决了图像阅读保护与配色算法解耦、跨窗口目标状态强隔离、截图生命周期管理与内存泄露防护、历史版本原子保存事务、Worker 超时防挂起等 6 大核心架构缺陷，并大幅提升了多窗口、大图壁纸与长会话运行时的系统稳定性。

---

## 2. 核心修复与改进

### 2.1 阅读保护与图像分析独立化 (R01)
- **无需生成配色即可保护**：导入壁纸后，直接点击开启「阅读保护」即可基于壁纸的真实像素计算对比度建议，无需先走耗时的配色生成流程。
- **内存有界与并发合并**：引入 LRU 缓存（上限 16 条目 / 64MB）与图片下采样机制（最大边长限制为 512px），多次切换或分析大图壁纸不会导致内存无限制膨胀。

### 2.2 跨窗口主题与场景强隔离 (R02, R03)
- **多窗口主题互不串色**：每个目标窗口维护独立的 `activeDocument`，窗口 A 切换场景或应用主题时，绝不误染窗口 B 的全局草稿。
- **异步操作防护**：在场景切换计算期间，若用户执行了手动恢复或锁定，迟到的异步结果将被自动废弃，杜绝反向覆盖。

### 2.3 宿主截图管理与防泄露 (R04, G04)
- **截图生命周期防护**：切换目标窗口或点击清除后，在途延迟返回的截图数据自动废弃，不在内存中复活。
- **敏感区域遮挡**：对比面板新增「遮挡敏感区域」选项，自动对聊天正文或输入框区域添加隐私保护滤镜。
- **对比滑块支持键盘微调**：分割对比滑块支持拖拽及键盘方向键微调，方便精细对比样式差异。

### 2.4 主题版本与历史事务一致性 (R05, G07)
- **落盘失败明确反馈**：遇到磁盘写入失败或权限异常时，系统返回明确的错误原因与事务状态，杜绝“虽然写入失败但 UI 显示保存成功”的假象。
- **任意双版本差异比对**：版本面板支持选择任意两个历史快照进行字段级对比（颜色、文字、壁纸、区域），并支持侧栏/聊天等区域的选择性局部恢复。

### 2.5 配色 Worker 容错与优雅退出 (R06, G05)
- **Worker Settle-Once**：为配色生成 Worker 线程增加了超时保护与异常退出清理机制，超时或取消后确保立即释放资源，下次生成立即可用。
- **角色锁定与局部采用**：配色生成面板新增强调色、主背景、面板色等字段锁定支持，并允许用户单项采用配色方案。

## 3. 升级与兼容性说明

1. **配置与数据兼容性**：
   - 完美兼容 v0.4.0 及早期版本的配置文件（`appearance.json`、`preferences.json`、`theme-library.json`）。
   - 保留 Schema Version 2 与 Theme Library Schema 1，历史版本数据无需手动迁移。
2. **便携式单文件升级**：
   - 直接运行 `Anti Face 0.4.1.exe` 即可自动识别原用户数据目录，旧有已安装的精选主题与个人自建主题完整保留。
3. **降级与回退**：
   - 0.4.1 生成的主题数据严格遵循既有协议规范，回退至 0.4.0 不会产生数据损坏。

---

## 4. 已知边界与使用建议

- **真实 Antigravity 宿主接入**：
  - 自动发现要求 Antigravity 已开启 CDP 调试端口（例如 `--remote-debugging-port=9222` 或默认端口）。
  - 若宿主未暴露工作区绝对路径，系统会以“来源受限（session-window）”模式提供保护，用户可通过面板中的「选择项目文件夹」手动关联本地代码目录以实现持久化项目绑定。
- **离线精选主题**：
  - 系统内置 20 套离线高质量主题，无需联网即可随时换肤或加入个人库。若用户修改过内置主题的副本，再次点击安装时系统会弹出警示以防止覆盖您的个性化定制。
